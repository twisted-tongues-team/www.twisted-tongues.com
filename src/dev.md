Twisted Tongues has no public API. Today the way to work with a project
programmatically is to save it to your computer — “Save to Computer…” inside
any project, or see [section 2.3 of the
manual](/manual#2.3-saving-a-project-to-your-computer) — and process the
file. That file is in a documented, stable format, and this is where it is
described:

- **[The export format](/dev/export-format)** — what is in a saved project
  file, a JSON Schema for it, and a Python reader and TypeScript types you
  can drop into your own code.

Let us know if there's some other API you were hoping for:
[twisted-tongues-team@googlegroups.com](mailto:twisted-tongues-team@googlegroups.com).
